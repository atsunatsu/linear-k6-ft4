# Firmware Input

## 中文
把**真实 0.3q 固件主 bin** 放到这个目录。

推荐文件名：

- `real-0.3q.bin`

不要把公开源码树里自己编出来的 bench 固件放这里。
这里只有一个目标：

- 真实、带数字模式入口、和你手里正在用的 `0.3q` 成品行为一致的固件 `bin`

## English
Place the **real 0.3q firmware main bin** in this folder.

Suggested filename:

- `real-0.3q.bin`

Do not place a bench build from the public source tree here.
This folder is only for the real firmware image that matches the digital-mode-capable `0.3q` behavior you already use.
