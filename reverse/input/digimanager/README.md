# DigiManager Input

## 中文
把真实 `UVK5DigManager` 二进制放到这个目录。

可以放：

- `UVK5DigManager.exe`
- `UVK5DigManager_v1.0.zip`

脚本会优先读取：

- 目录里的第一个 `.zip`
- 否则第一个 `.exe`

## English
Place the real `UVK5DigManager` binary here.

Accepted inputs:

- `UVK5DigManager.exe`
- `UVK5DigManager_v1.0.zip`

The script will prefer:

- the first `.zip` in this folder
- otherwise the first `.exe`
