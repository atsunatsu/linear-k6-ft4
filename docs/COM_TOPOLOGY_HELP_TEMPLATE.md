# COM 拓扑协助模板 / COM Topology Help Template

这个模板适合“还没开始抓包，只是先确认 COM”的测试者。  
This template is for testers who have not started capture yet and only want help confirming the COM ports.

## 1. 最少请回这些信息 / At Minimum Please Send These

```text
WSJT-X = COM?
DigiManager = COM?
```

如果现在还填不出来，也没关系，继续看下面。  
If you still cannot fill them in, that is okay. Continue below.

## 2. 请附上这 3 张截图 / Please Attach These 3 Screenshots

1. `WSJT-X` 设置页  
   `WSJT-X` settings page
2. `DigiManager` 设置页  
   `DigiManager` settings page
3. Windows `设备管理器 -> Ports (COM & LPT)`  
   Windows `Device Manager -> Ports (COM & LPT)`

## 3. 请告诉我们这些情况 / Please Tell Us These Things

- 当前固定频点链路是否能正常工作？  
  Does the current fixed-frequency chain work normally?
- 你是否知道自己在用什么虚拟串口工具？  
  Do you know which virtual COM tool you are using?
- 你觉得哪个 `COM` 可能属于 `WSJT-X`？  
  Which `COM` do you think may belong to `WSJT-X`?
- 你觉得哪个 `COM` 可能属于 `DigiManager`？  
  Which `COM` do you think may belong to `DigiManager`?

## 4. 你现在不需要做什么 / What You Do Not Need To Do Yet

- 不需要先抓包  
  You do not need to capture yet
- 不需要先改代码  
  You do not need to change code yet
- 不需要先理解协议  
  You do not need to understand the protocol yet

## 5. 一句话目标 / One-Sentence Goal

**先把两个 COM 口找出来，再决定要不要进入抓包阶段。**  
**Find the two COM ports first, then decide whether to move to the capture stage.**
